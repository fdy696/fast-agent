## 1. 标题生成函数

位置：放在 `src/agent/prompts.py`（和 `TITLE_PROMPT` 放一起，不建新模块）。

策略：

| 条件 | 处理 | LLM 调用 |
|------|------|----------|
| 首条消息 ≤20 字符 | 直接清洗截断当标题 | 零 |
| 首条消息 >20 字符 | 调 `COMPRESS_MODEL` 提炼 | 1 次 |
| LLM 失败 | 回退到清洗截断 | — |

```python
TITLE_PROMPT = """将下方用户首条消息提炼为一段不超过 12 个字的简短会话标题，
用于会话列表展示。要求：
1. 只基于用户消息本身，不要回答问题、不要带入系统提示或历史上下文。
2. 指向用户意图（如"规划北京三日游"、"查北京天气"），不要带"标题:"等前缀。
3. 若消息已是短语，可直接精简；若过长则概括核心意图。
只返回标题文本。"""

TITLE_THRESHOLD = 20
TITLE_MAX = 20


def _clean(raw: str) -> str:
    return " ".join(raw.split())[:TITLE_MAX]


async def generate_title(first_user_msg: str) -> str:
    from agent.model_client import call_compress_model

    cleaned = _clean(first_user_msg)
    if len(cleaned) <= TITLE_THRESHOLD:
        return cleaned
    try:
        res = await call_compress_model(
            messages=[{
                "role": "system",
                "content": TITLE_PROMPT + "\n\n【用户消息】\n" + first_user_msg,
            }]
        )
        title = _clean(res.choices[0].message.content or "")
        return title or cleaned
    except Exception:
        logger.warning("title generation failed, fallback to truncation")
        return cleaned
```

### 1.1 新建 `call_compress_model`

`src/agent/model_client.py` 目前只有 agent 构建逻辑，需要新增一个独立的压缩模型客户端：

```python
# src/agent/model_client.py 新增

_compress_client: AsyncOpenAI | None = None


def _get_compress_client() -> AsyncOpenAI:
    global _compress_client
    if _compress_client is None:
        _compress_client = AsyncOpenAI(
            api_key=settings.DEEP_SEEK_API_KEY or settings.API_KEY or "dummy",
            base_url=settings.AGENT_BASE_URL,
        )
    return _compress_client


async def call_compress_model(
    messages: Iterable[ChatCompletionMessageParam],
) -> ChatCompletion:
    return await _get_compress_client().chat.completions.create(
        model=settings.COMPRESS_MODEL,
        stream=False,
        messages=messages,
    )
```

> 复用已有的 `AsyncOpenAI` 模式（参照已存在的 `init_agent`），只是 model 不同、非流式。

## 2. 集成方式：fire-and-forget

改 `AgentService.stream_ag_ui()`，**不在 on_complete 里取 task 结果**。

### 2.1 触发入口

```python
# stream_ag_ui() 早期，get_or_create 之后:
conv, is_new = await self.conv_repo.get_or_create(
    session_id=session_id, user_id=user_id,
)

if is_new and user_content:
    asyncio.create_task(self._auto_title(conv.id, user_content))
```

> 传 `conv.id` 而不是 `conv` 对象 —— 避免跨 session 问题（见 2.2）。

### 2.2 `_auto_title` 实现

```python
async def _auto_title(self, conv_id: int, first_msg: str) -> None:
    """fire-and-forget: 标题生成 → 写 DB，不阻塞主流程."""
    from db.session import AsyncSessionLocal
    from repositories.conversation import ConversationRepository
    from agent.prompts import generate_title

    try:
        title = await generate_title(first_msg)
    except Exception:
        return  # 生成失败不影响任何事

    try:
        async with AsyncSessionLocal() as db:
            repo = ConversationRepository(db)
            conv = await repo.get_by_id(conv_id)
            if conv:
                await repo.update_title(conv, title)
    except Exception:
        logger.warning("Failed to persist title for conv %s", conv_id)
```

**关键设计**：在 `AsyncSessionLocal` 里用 `get_by_id(conv_id)` 重新查询，而不是复用 `stream_ag_ui` 的 session 里的 `conv` 对象。SQLAlchemy async 模式下跨 session 使用 ORM 对象是不安全的——旧 session 的对象在新 session 里不被追踪，commit 可能不生效。

### 2.3 为什么比 on_complete 里取 task 结果更好

- 不需要 task 引用、不需要超时逻辑
- 标题生成和 Agent 推理完全并行
- SSE 流提前断开也不影响标题写入
- 标题可能比流结束更早写完，会话列表更快看到结果

## 3. 附带修复：`get_or_create` 并发安全

> 这是一个独立 bugfix，不属于标题功能，一并处理。

```python
from sqlalchemy.exc import IntegrityError

async def get_or_create(self, *, session_id, user_id, title="New Chat"):
    existing = await self.get_by_session_id(session_id=session_id, user_id=user_id)
    if existing:
        return existing, False
    try:
        conv = Conversation(session_id=session_id, user_id=user_id, title=title, ...)
        self.db.add(conv)
        await self.db.commit()
        await self.db.refresh(conv)
        return conv, True
    except IntegrityError:
        await self.db.rollback()
        return await self.get_by_session_id(session_id=session_id, user_id=user_id), False
```

## 5. 验证标准

| # | 场景 | 验证方式 | 预期结果 |
|---|------|---------|----------|
| 1 | 新会话首条消息 | `GET /all_conversation_list` | `title != "New Chat"`，为提炼后的标题 |
| 2 | 已有会话继续对话 | 发第二条消息后查 `title` | 标题与第一条消息后一致，未被覆盖 |
| 3 | 短消息（≤20字） | 查日志 | 无 compress_model 调用 |
| 4 | compress_model 不可用 | 错误配置或网络断开后发消息 | 会话正常创建，标题回退为清洗截断 |
| 5 | 并发首条消息 | 两个请求同时打到同 session_id | 无 IntegrityError，会话正常创建 |
