## 第 2 步：限流闭环

| # | 动作 | 文件 |
|---|------|------|
| 1 | 新增 `RATE_LIMIT_DEFAULT = "200/day,50/hour"` | `src/core/config.py` |
| 2 | `limiter` 传入 `default_limits` | `src/core/rate_limit.py` |
| 3 | 删除 `apply_rate_limit`，直接 `@limiter.limit(...)` | `src/api/v1/auth/auth.py` |
| 4 | 去掉 `__import__` hack，顶部直接 import | `src/__init__.py` |

**`src/core/rate_limit.py` 最终**：

```python
from slowapi import Limiter
from slowapi.util import get_remote_address

from core.config import settings

limiter = Limiter(
    key_func=get_remote_address,
    default_limits=[settings.RATE_LIMIT_DEFAULT],
)
```

**`src/api/v1/auth/auth.py` 最终**：

```python
from core.rate_limit import limiter

@router.post("/login", summary="登录")
@limiter.limit("5/minute")
async def login(request: Request, ...):
    ...

@router.post("/refresh", summary="刷新token")
@limiter.limit("10/minute")
async def refresh_token(request: Request, ...):
    ...
```

**`src/__init__.py`**：顶部加 `from core.rate_limit import limiter`，`create_app()` 内 `app.state.limiter = limiter`。

## 不做

```text
不做 RATE_LIMIT_STORAGE_URL          → 默认内存够用，需要 Redis 的人自己改一行
不做 response_model 泛型体系          → to_dict() 简单直白
不做 Repository 分层异常              → HTTPException 一眼看懂，等项目长大再加
不做 RESTful alias 兼容旧路径        → 没有历史调用方
不做 FileMapping FK + Alembic 迁移    → 注释说明设计意图就够了
不做递归脱敏                          → flat 版覆盖了当前所有场景
不做审计异步化                        → 同步写够用，后续单独做
```
